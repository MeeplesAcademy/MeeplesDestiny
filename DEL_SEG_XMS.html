Import Segment Request Logs

Upload .txt log files — select multiple days and both versions at once

Select one or more "DEL SEG REQS" .txt exports. A file is treated as the XMS version when its filename contains "XMAS" or "XMS" (e.g. "DEL XMAS SEG REQS 12-29-25 MON.txt"); otherwise it's the secular version. The day is read from the filename first, then from the file's header line. Importing a file replaces only that day's matching version — the other version and other days are left alone. Lines whose title/artist columns can't be split cleanly are flagged in amber.
